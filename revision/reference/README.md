# Historical aggregate reference

`legacy_audit.json` packages the existing disclosure-controlled source-workstation
audit tables, together with their source paths and SHA-256 hashes. It contains
manuscript cells, aggregate reproduction comparisons, fairness normalization
components and aggregate vital-sign diagnostics. No records or identifiers are
included. These are historical evaluation references, not server retraining
results. Final analysis maps them to the actual corrected server aggregates;
incompatible definitions remain explicitly labelled.
